BigInt Math Engine

Explore the exact number-theoretic mechanics invented by Rivest, Shamir, and Adleman (RSA). Observe prime selection, Euler's totient function, modular multiplicative inverse, and exponentiation modulo n in real time.

Step 1: Compute Modulus (n) & Euler's Totient φ(n)
n = p × q = 61 × 53 = 3233
φ(n) = (p - 1) × (q - 1) = 60 × 52 = 3120

The modulus n is public and defines the keyspace. The totient φ(n) represents the count of positive integers up to n that are coprime to n and must remain strictly secret.

Step 2: Key Pair Generation (e and d)
Public Exponent (e): 17 (Coprime: gcd(e, φ(n)) = 1)
Private Exponent (d): d ≡ e-1 (mod φ(n)) → 2753
Verification: (e × d) mod φ(n) = (17 × 2753) mod 3120 = 1
Public Key: (e = 17, n = 3233) • Private Key: (d = 2753, n = 3233)

Applied Web Security Principles

Zero-Trust Standard

This application adheres to modern cryptographic hygiene and web application security standards to guarantee true confidentiality and tamper resistance.

Client-Side Zero-Knowledge

All key generation, encryption, and decryption routines run directly in browser volatile memory using Web Cryptography API. Private keys are never logged, serialized, or transmitted to any server.

Optimal Padding (OAEP)

Unlike vulnerable textbook RSA, this system employs RSA-OAEP with SHA-256. OAEP introduces randomized Feistel padding, completely neutralizing Coppersmith's theorem and adaptive chosen-ciphertext attacks.

Hybrid Cryptosystem

Combines the convenience of asymmetric RSA with the high throughput of AES-256-GCM. Arbitrary-sized files are shielded using authenticated symmetric ciphers with randomized 96-bit nonces.

XSS & Storage Isolation

Sensitive private keys are explicitly isolated from unencrypted LocalStorage and SessionStorage, eliminating common cross-site scripting (XSS) extraction vectors.
